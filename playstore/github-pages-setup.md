# GitHub Pages Setup For Renewly

## Details To Use

- Repository: `harish-lingala/renewly`
- Branch: `main`
- Recommended GitHub Pages folder: `/docs`
- Privacy policy file: `docs/privacy-policy.html`
- Privacy policy URL for Play Console: `https://harish-lingala.github.io/renewly/privacy-policy.html`
- Pages home URL: `https://harish-lingala.github.io/renewly/`

## Where To Find GitHub Pages Settings

1. Open GitHub.
2. Open the `harish-lingala/renewly` repository.
3. Click `Settings`.
4. In the left sidebar, click `Pages`.
5. Under `Build and deployment`, select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/docs`
6. Click `Save`.

## If Pages Is Not Working

- Make sure the repository is public, unless your GitHub plan supports Pages for private repositories.
- Wait 5 to 10 minutes after saving Pages settings.
- Open the privacy policy URL in an incognito/private browser.
- If it still shows 404, confirm the Pages source folder is `/docs`, not `/root`.

## Play Console Privacy URL

Paste this in Play Console:

`https://harish-lingala.github.io/renewly/privacy-policy.html`
