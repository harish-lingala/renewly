## Testing Track

Start with Internal Testing:

1. Go to Test and release > Testing > Internal testing.
2. Create new release.
3. Upload the `.aab`.
4. Release name: `1.0 internal prototype`
5. Release notes: copy from `store-listing.md`.
6. Add tester emails.
7. Roll out to internal testing.

Then prepare Closed Testing:

1. Go to Testing > Closed testing.
2. Create a track named `renewly-beta`.
3. Add at least 12 tester emails.
4. Share the opt-in link.
5. Keep testers opted in for 14 continuous days.
6. Apply for production access after the requirement is met.
