# Renewly Data Safety Draft

Use this as a guide when completing Play Console's Data Safety form. Answer according to the current prototype only.

## Current Data Model

Renewly stores user records locally on the device/browser storage in this prototype. Cloud sync is not enabled yet.

Users may manually enter:

- Name or owner label
- Vehicle or device details
- Policy, warranty, service, PUC, or contract dates
- Provider, seller, or service center names
- Amount, premium, value, serial/reference/policy numbers
- Notes
- Document/photo references

## Data Shared With Third Parties

Current answer: No.

Reason: The prototype does not send user records to a backend or third-party service.

## Data Collected

Current answer: No, if Play Console defines collection as data transmitted off the user's device to you or third parties.

If you later add cloud sync, analytics, crash reporting, ads, login, or payment, this answer must change.

## Security Practices

- Data is stored locally on the user's device in this prototype.
- Users can export a backup file.
- No cloud transfer is currently enabled.

## Ads Declaration

Current answer: No, the app does not contain ads.

Change this later if AdMob or any ad SDK is added.

## App Access

Current answer: All app functionality is available without login or special access.

## Target Audience

Recommended: 18 and older.

Reason: The app may store insurance, policy, licence, and household document reminders.

## Content Rating Notes

Renewly is a utility/productivity app. It does not contain gambling, violence, adult content, public user-generated content, or social networking features.
